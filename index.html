Khối Kiến Thức Trọng Tâm

Chương trình học bao quát từ nền tảng giao thức mạng đến phát triển sản phẩm web chuẩn production.

🌐

Kiến trúc Web & Giao thức

Mô hình Client-Server, HTTP/1.1, HTTP/2, HTTP/3, HTTPS/TLS, DNS, cơ chế Caching, WebSocket và vòng đời một Web Request.

HTTP/HTTPS DNS TCP/IP WebSocket
🎨

Phát triển Frontend Hiện đại

HTML5 ngữ nghĩa, CSS Grid/Flexbox, JavaScript ES6+, tư duy xây dựng Single Page Application (SPA), Component-based và UI State Management.

HTML5 CSS3 ES6+ React/Vue
⚙️

Backend & Cơ sở dữ liệu

Xây dựng Web Server, RESTful APIs chuẩn mực, GraphQL, xử lý bất đồng bộ, thao tác với SQL (PostgreSQL/MySQL) và NoSQL (MongoDB/Redis).

Node.js Express PostgreSQL MongoDB
🛡️

Xác thực & Bảo mật Web

Cơ chế xác thực State (Session/Cookie) vs Stateless (JWT), OAuth 2.0, OpenID Connect, phòng chống lỗ hổng OWASP: XSS, CSRF, SQL Injection, CORS.

JWT OAuth2 OWASP Top 10 CORS
☁️

Dịch vụ Trực tuyến & Cloud

Điện toán đám mây (IaaS, PaaS, SaaS), kiến trúc Microservices, Message Queue, Container hóa với Docker và luồng tích hợp tự động CI/CD.

Docker AWS/GCP CI/CD Microservices
⚡

Hiệu năng & Giám sát Web

Tối ưu hóa Core Web Vitals, CDN (Cloudflare), Nginx Reverse Proxy, Load Balancing, cơ chế Logging, Monitoring và Rate Limiting.

Nginx CDN Redis Cache Web Vitals
📑

DOM & Event-Driven JS

Hiểu sâu về DOM Tree, Virtual DOM, Event Bubbling, Closures, Promises và Async/Await trong JavaScript hiện đại.

DOM Manipulation Async/Await Event Loop
📐

Responsive Design & CSS Layouts

Thiết kế giao diện thích ứng đa màn hình với Flexbox, Grid, CSS Variables và tối ưu hóa trải nghiệm người dùng (UX).

CSS Flexbox CSS Grid Mobile First
🗄️

Thiết kế API & Kiến trúc Dữ liệu

Nguyên tắc RESTful API, mã trạng thái HTTP, thiết kế lược đồ quan hệ, Indexing và tối ưu truy vấn cơ sở dữ liệu lớn.

RESTful API Relational Schema Indexing
🔒

Bảo mật & Quản trị Phiên

Phân quyền Role-based Access Control (RBAC), mã hóa mật khẩu với Bcrypt/Argon2 và bảo vệ các Endpoint nhạy cảm.

RBAC Bcrypt Security Headers
🐳

Container & Triển khai Ứng dụng

Đóng gói ứng dụng Fullstack bằng Docker, viết Dockerfile, docker-compose và triển khai lên các nền tảng đám mây.

Docker Docker Compose Vercel/Render
🔄

Dịch vụ Realtime & Microservices

Xây dựng hệ thống giao tiếp tức thời qua Socket.io/WebSocket và chia sẻ tải dịch vụ qua kiến trúc hướng dịch vụ.

WebSocket Socket.io Event-Driven

Dịch vụ Trực tuyến, Docker & Cloud
